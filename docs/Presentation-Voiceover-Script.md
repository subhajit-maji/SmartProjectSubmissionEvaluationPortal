# Easy Presenter Script — 10 Slides

## How to present

Press **F5** to start. The slide animations play automatically. After each slide finishes, click once to continue. This talk takes about 2 minutes; speak slowly and use your own words.

**Memory cue:** Propose → Decide → Submit → Review → Revise → Approve.

## Slide 1 — Smart Project Submission & Evaluation Portal

Good morning. My project is a portal for academic projects. It helps students submit their work and get feedback in one place.

## Slide 2 — Project work gets fragmented between hand-offs

Proposals, report files, and comments can end up in different places. The portal keeps them together, so it is easier to see what happens next.

## Slide 3 — Three roles. One shared project journey.

There are three roles: administrator, student, and faculty. The administrator decides proposals, the student submits work, and the faculty member reviews it.

## Slide 4 — A small web stack with a private report store

The browser sends requests to the PHP app. PHP checks the user and uses MySQL for project records. PDF files stay private until an allowed user downloads them.

## Slide 5 — A proposal decision sets up the review path

The student sends a proposal. The administrator approves or rejects it. If approved, a faculty guide is assigned and report submission becomes available.

## Slide 6 — Feedback drives a controlled revision loop

Faculty reviews the report and can ask for a change. The student uploads a new PDF, and the earlier feedback stays with the project.

## Slide 7 — Security checks sit on the critical paths

The app protects accounts and forms, checks uploaded PDFs, and verifies permission before a report is downloaded.

## Slide 8 — The same workflow adapts from phone to desktop

We checked the layout from 320 to 1440 pixels. The page fits the screen, and wide tables scroll inside their own area.

## Slide 9 — The main path and key guardrails were exercised

We manually tested proposal approval and rejection, report upload, revision, final approval, and blocked downloads for unrelated users.

## Slide 10 — One project. One current report. Feedback that stays attached.

That is the project: one place for the current report and its feedback. Thank you. Are there any questions?
